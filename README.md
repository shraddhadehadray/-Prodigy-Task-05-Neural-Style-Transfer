# Prodigy Infotech - Task 05

## Neural Style Transfer

This project applies the artistic style of one image to another image using Neural Style Transfer.

### Technologies Used
- Python
- TensorFlow
- TensorFlow Hub
- NumPy
- Matplotlib
- Pillow
- Google Colab

### How It Works
1. Upload a content image.
2. Upload a style image (painting).
3. The Neural Style Transfer model combines the content and artistic style.
4. The final stylized image is generated.
